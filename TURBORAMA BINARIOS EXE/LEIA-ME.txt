TURBORAMA - FIX CS0012 WINDOWSBASE / DEPENDENCYOBJECT

Problema:
VideoPlayerForm.cs usa:

ElementHost
MediaElement
System.Windows.Controls
System.Windows.Media

MediaElement depende de DependencyObject.
DependencyObject fica em WindowsBase.dll.

Erro:
CS0012 - O tipo DependencyObject esta definido em assembly nao referenciado.
Adicionar referencia WindowsBase.

Correcao:
Este patch adiciona no RetroBat.csproj:

WindowsBase
PresentationCore
PresentationFramework
WindowsFormsIntegration
System.Xaml

Como usar:
1. Extraia dentro da pasta onde esta RetroBat.sln.
2. Feche Visual Studio.
3. Rode:
   Fix_WPF_WindowsBase_CS0012.bat
4. Abra a solution.
5. Compile:
   Release | Any CPU

Se ainda der erro:
Instale pelo Visual Studio Installer:
- .NET desktop development
- .NET Framework 4.8 Developer Pack / Targeting Pack
