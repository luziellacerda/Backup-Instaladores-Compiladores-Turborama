# TurboRama PIX Comercial v14

Esta versão adiciona o editor gráfico externo `CONFIGURAR-ACCESS-TOKEN-PIX.exe`, retomada automática após falha de internet e cache do endereço validado.

- Configuração do proprietário: START, protegida pela senha administrativa.
- Compra do cliente: SELECT, livre e sem senha.
- Credencial: `.emulationstation\pix\secret.dat`, protegida por Windows DPAPI.
- Cadastro: `.emulationstation\pix\owner-settings.json`.
- Editor instalado: `D:\emulationstation\CONFIGURAR-ACCESS-TOKEN-PIX.exe`.

O instalador compilado é publicado como arquivo da Release, não dentro do histórico Git.
