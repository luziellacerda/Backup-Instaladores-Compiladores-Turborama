PASTA DOS SLIDES - TURBORAMA

Coloque aqui os arquivos usados no carrossel automático da página principal index.html.

Arquivos aceitos:
- Imagens: .jpg, .jpeg, .png, .webp, .svg
- Vídeos: .mp4, .webm, .ogg

Como usar:
1. Copie seus arquivos para esta pasta: assets/slides/
2. Abra o arquivo config.js
3. Edite a lista slidesMobile, exemplo:

slidesMobile: [
  { tipo: "imagem", arquivo: "assets/slides/minha-imagem-01.jpg", etiqueta: "Sistema", titulo: "Visual premium", texto: "Texto que aparece abaixo do slide." },
  { tipo: "video", arquivo: "assets/slides/meu-video-01.mp4", etiqueta: "Demo", titulo: "Sistema funcionando", texto: "Vídeo curto mostrando o sistema." }
]

Tamanho recomendado:
- Imagens horizontais: 1920 x 1080 px
- Imagens verticais: 1080 x 1680 px ou 1080 x 1920 px

Dica:
Use vídeos curtos de 8 a 20 segundos para deixar a apresentação rápida e profissional.
